# 心得標注工具

一個單一 HTML 檔的網頁工具，用來標注化妝品心得裡的文字片段屬於哪些主題標籤。

## 怎麼用

1. 用瀏覽器打開 `index.html`（需要網路，xlsx 解析用 CDN 載入的 SheetJS）。
2. 輸入標注者名字。
3. 上傳 xlsx 或 csv（要有「編號」和「心得內容」欄位），或按「載入範例」試用。
4. 用滑鼠圈選文字，按數字鍵 1–7 或點右邊的標籤來標注。
5. 每篇可標成「完成」「跳過」或「無可標內容」。
6. 按「匯出 CSV」或「匯出 JSON」下載結果。

標注會自動存在瀏覽器的 localStorage，不會上傳到任何伺服器。

## 檔案

- `index.html`：整個工具。
- `SPEC.md`：需求與設計說明。
